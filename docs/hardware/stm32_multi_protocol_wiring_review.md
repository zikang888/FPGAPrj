# STM32F407 ↔ AC820 后续协议接线核对（2026-10-15）

## 已核实的来源与边界

用户提供的 `D:\AC820+SOC+FPGA开发板管脚资源定义表.xlsx` 的唯一工作表
“安路飞龙 FPGA侧资源管脚”在第 104–139 行将下列 FPGA 球位列为
“通用扩展接口 P7”资源。该表**没有 P7 实体针脚序号**，不能仅凭球位推导
排针的第几针。现有 `pin_assignment.md` 对 W5、AA9 等球位的协议分配仍是
预留方案，不代表线路已接或 PL 已实例化监听器。

| 预留信号 | FPGA 球位 | 表格行 | STM32 侧候选信号 | 目前安全方向 |
| --- | --- | ---: | --- | --- |
| UART RX 监听 | W5 | 139 | USART3 TX / PD8 | FPGA 输入 |
| UART 回传线监听 | AA9 | 136 | USART3 RX / PD9 的实际总线节点 | FPGA 输入，暂不驱动 |
| I²C SCL 监听 | AA6 | 133 | I²C1 SCL / PB6 | FPGA 输入 |
| I²C SDA 监听 | V8 | 130 | I²C1 SDA / PB7 | FPGA 输入 |
| CAN TXD 监听 | W8 | 131 | STM32 CAN1 TX / PD1 到收发器 TXD 的逻辑节点 | FPGA 输入，暂不驱动 |
| CAN RXD 监听 | AA11 | 128 | 收发器 RXD 到 STM32 CAN1 RX / PD0 的逻辑节点 | FPGA 输入 |

已验证的 SPI 四线仍为 U12/U11/U10/U9（表格第 104–107 行）；项目既有
P7-1/2/3/4 对应关系来自先前上板接线记录，不是这张表直接给出的针号。

## 接线前必须确认

1. 用 AC820 原理图、P7 排针丝印或断电连续性测试，确认上述球位对应的
   **实体针脚序号**；在确认前不要按表格行号或球位名称猜针号接线。
2. STM32 与 AC820 共地，双方数字 IO 均按 3.3 V 核对。FPGA 保持高阻
   输入，不把预留的 `uart_tx`/`can_tx` 名称理解为已经允许驱动总线。
3. I²C 的 PB6/PB7 属于开漏总线，确认外接 AT24C256 的供电及 3.3 V
   上拉；FPGA 只旁路观察，不加推挽输出。
4. CAN 必须经 SN65HVD230 等兼容收发器及正确终端电阻。FPGA 只能接
   收发器的 **3.3 V 数字 TXD/RXD 侧**，不得把 CANH/CANL 直接接到 FPGA。
   当前 STM32 `CAN_MODE_NORMAL`，无外部应答节点时不能把 `can loop`
   的命令存在视为已完成 CAN 真闭环。
5. USART3 的 `uart loop` 需要明确谁负责回传。若 PD8→PD9 是本地短接，
   FPGA 可同时旁路观察两个节点；若希望 FPGA 主动应答，需另设计输出、
   电平与方向保护，不能沿用当前输入监听方案。

当前 PL 发布 BIT 只具备真实 SPI 监听；UART/I²C/CAN 在 UI 中继续标记
`NOT WIRED/OFFLINE`，直到各自 RTL、BD、约束、BIT、PS 能力位和实板证据
配套完成。
