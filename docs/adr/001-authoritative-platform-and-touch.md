# ADR-001：正式工程与触摸平台基线

- 状态：已接受
- 日期：2026-09-23

## 决策

`D:\fpga_class\Multi_protocol` 是多协议通信分析与故障测试平台的唯一正式工程。
`D:\fpga_class\oldtouch_ui\touch_ui` 仅作为小梅哥官方 5 寸 800×480 RGB 屏和
Goodix GT911 触摸链路的已验证来源，不作为独立产品路径继续开发。

正式工程保留现有的多协议 PL 核、AXI 寄存器、VDMA/VTC 显示链路和 PS UI，
只从参考工程继承板级参数、引脚约束和经过验证的 GT911 配置数据。

## 固定硬件参数

- 器件：`xc7z020clg484-2`
- 显示：800×480，RGB565，VDMA MM2S
- 触摸：Goodix GT911，7 位 I2C 地址 `0x14`
- I2C0：MIO50/MIO51
- GT911 INT/地址选择：MIO0
- GT911 RST：PS EMIO GPIO[0]，PS GPIO 54，封装引脚 R15

## 软件约定

触摸驱动的正式 API 使用 `gt911_*` 前缀。历史 `gt9147_*` 名称与实际芯片不符，
不保留为第二套接口；SDK 生成目录属于构建产物，源码以 `software/src` 为准。

## 后果

后续协议功能、故障注入、事件快照和 UI 页面都在本工程上迭代。参考工程中的
信号发生器演示主程序不迁入正式路径，避免覆盖多协议核心和平台自检程序。
