# 单次捕获与保存测试错误波形回看（2026-10-31）

PS 界面更新，未修改 RTL、STM32 或 CAN FORM 启用状态。

## 操作

- 波形页保留原单次捕获；“测试波形回看”读取当前协议最近的保存测试。
- “返回单次捕获”保留原独立捕获；“重新捕获”才主动启动新捕获。
- 测试页开始新测试，发送数据，结束并保存，再从波形页或错误页进入回看。
- 历史页打开指定测试，“波形回看”查看该轮异常；“返回事件列表”恢复列表。
- “上一异常／下一异常”按事务浏览。同一事务多项错误归为一组，并显示错误标签及项数。
- 无保存记录、无异常明细、错误计数存在但明细已截断，均明确提示，不借用正常事务冒充错误波形。

## 数据范围

显示保存的解码事件重构轨迹，不是新增原始数字采样。CAN 仅显示保存的负载位，无法定位的 STUFF／CRC／ACK 原始位不补画。
历史仍保留最近 8 轮、每轮最多 256 条事件，RAM 掉电丢失。回看不修改保存记录或原单次捕获缓存。
