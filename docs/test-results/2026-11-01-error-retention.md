# 异常事务保留版（2026-11-01）

本机实板已验证；尚未提交或推送。权威源码仍为工程 software/src 与 fpga/rtl，本目录是配套发布文件。

## 修复行为

正式 TESTS 测试使用独立的异常事务保留模式：正常事务仅累计计数，结束后释放临时空间；异常事务整笔提交保存，后续正常流量不会覆盖。停止后历史及错误波形回看使用这些异常明细。
SPI 9F 的短事务、超长和错误 ID 在 END 处按语义判定；其余协议按启用的事件类型判定，I2C 忙 NACK 仅 INFO、不存入异常档案。
单次捕获保持原环形快照模式，仍可查看正常数据。
异常存档仍最多 256 条事件，最近 8 轮 RAM 历史。档案满后保留旧异常，设置“异常存档已满”提示；不声称无限容量。长事务可部分保存并提示容量不足。
这是解码事件轨迹，不是新增原始数字电平采样。Partial、Break 等原本没有完整字节的项目仍无法补画电平。

UART 页面已移除奇偶校验、波特率错误项，只剩停止位、Break、短事务；CAN 页面移除总线关闭，只剩缺 ACK、Stuff、CRC，按三行重新排布。停用的 CAN FORM/TX BITS 和 I2C STUCK 未恢复。

## 验证

- 真实事件 ABI 仿真：四协议各 1000 事务，第 500 笔异常保持；还覆盖容量满不覆盖、缺 END、Busy INFO、SPI 长度语义及原捕获回归。
- 16 项主机检查、生产 UI 渲染/触摸回归、保存回看回归通过。
- Vivado SDK 2018.3 全量新构建。WNS +0.716 ns，TNS 0；保持及脉宽均无失败端点。
- 新 HDF 重建 BSP/ELF，JTAG 读回 SYS_ID=4D505254，VERSION=00010009，CAPABILITIES=000003FF。
- 四协议两轮实板测试，每组 100 事务，共 800 逻辑事务：一次模式第 50 笔错误；周期模式每 10 笔错误、共 10 次。

| 协议与测试错误 | 第50笔异常：总事件/保存明细 | 周期10次异常：总事件/保存明细 |
|---|---:|---:|
| SPI Short | 598 / 4 | 580 / 40 |
| UART Bad Stop | 992 / 2 | 920 / 20 |
| I2C Address NACK | 2284 / 4 | 2140 / 40 |
| CAN CRC | 1992 / 12 | 1920 / 120 |

每组保存的异常事务数分别为 1 和 10，存档未满。CAN 同帧 CRC 与缺 ACK 各一项，错误项数分别为 2、20；不是两倍异常帧。
本轮实板大流量覆盖上述四种代表错误，不将其扩大为所有错误类型的大流量逐项验收。
读取实际事件窗口及 LCD 帧缓冲验证。截图选择由调试器写 UI 页/索引完成，未篡改事件或计数；触摸手势沿用已通过回归逻辑。
