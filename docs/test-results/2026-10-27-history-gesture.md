# HISTORY 点按与拖动修复（2026-10-27）

问题：历史列表在手指按下时立即进入详情，尚未判断是否拖动；列表原来
32 px 行高，8 条全部放入一屏，也没有列表滚动位置和滚动条。详情页的
事件滚动已有实现，但与列表点击路径不同。

修复：

- 列表行改为抬手确认；累计任一轴移动达到 10 px 后取消打开。
- 纵向拖动按像素更新位置；触及边界或拖回原点均不转为点击。
- 小幅抖动仍可点按；同一行、同一记录 ID、同一页面才允许释放时打开。
- 行高 44 px，8 条保留容量不变；列表视口 122～377 px，满列表可滚动 96 px。
- 显示列表滚动条；点中行的计算包含滚动偏移；返回保留列表位置。
- 保存新轮次时回到最新记录；列表手势与详情事件手势使用各自位置。
- 修复只涉及 PS UI；BIT/HDF/init 与 2026-10-26 配套链相同。

   页面变更、历史变更、空列表与不足一屏的列表。
