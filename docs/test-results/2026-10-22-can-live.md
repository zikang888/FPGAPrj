# CAN LIVE 叠加、位错误与 Bus-off 验证记录

日期：2026-10-22；修改前基线 `8c2e5c7`。最终源提交、完整 ARM 大小和 HEX 校验值记录在 [发布目录](../../stm32_f407/firmware/releases/README.md)。

## 实现

增加 PA1/TIM2_CH2 硬件 SOF 触发和 PA2/TIM2_CH3 单次 PWM，驱动独立收发器 I；A 使用真实 bxCAN 发送并由 CAN1_SCE IRQ 捕获位错误与 BOFF。新增 disturb/bit/busoff 场景，有限次数、停止、超时、恢复前后状态与失败持锁。

原 runner/logger、20 项 `mc_faults.c`/case ID、Core/IOC 和规则保持不变。板级菜单 15/19 在故障配置下改派 LIVE，16～18 仍 RAW。默认版禁用 LIVE；故障版允许但不自动运行。

## 主机验证：9/9 PASS

| 测试 | 内容 |
|---|---|
| 原六组测试 | 协议编排、会话、默认/故障 CAN HAL、RAW 生成/关闭检查继续通过 |
| mc_can_live_tests | 对帧号 1～10000 计算真实 DATA 隐性位；检查 25%～90% 窗口覆盖采样点；严格参数、Bus-off 次数/间隔/every 边界 |
| mc_can_session_tests（新增） | 缺 ACK 不能通过 bit；真实位错误证据通过；BOFF 命中提前结束；无 BOFF 到上限必失败；无注入证据的 BOFF 不通过 |
| mc_can_live_disabled_tests | 默认关闭时无硬件回调，不能开始 LIVE 或持有资源 |
| mc_can_live_hal_tests | 将真实适配源编译到小型寄存器模型：资源/已用引脚拒绝、硬件 SOF 而非软件 CEN、PWM/LEC/TX 证据、缺跳线、假边沿、迟到 IRQ 且 CNT 回零、BOFF 与恢复超时/重试、配置还原 |

模型手动驱动寄存器/IRQ，能检查软件判定和恢复路径，不能证明实际电气波形、时序延迟、错误计数增长或物理 Bus-off 已发生。没有把发送次数映射为假的 BOFF。

## ARM 与兼容检查

Keil 构建脚本现分离 MC_ENABLE_CAN_LIVE：default 清除三项 CAN 故障宏；can_fault 开启 CAN_FAULTS、RAW_GPIO、LIVE，并记录 BUILD 源版本。两个配置均完整构建，要求 0 error / 0 warning，不是单源文件编译。

检查专用 TIM2/CAN1_SCE 强 IRQ 仅存在于 LIVE 配置，旧默认 IRQ 不重写；TIM2 与 RAW TIM1 分开且会话互斥。检查源规则/旧协议/引脚未改，以及发布 HEX 地址/校验和/向量和 Git 字节一致性。

## 实板待验证
